# TSUX

okiz - A package installer that is smaller than most and is also not idiotproof

## Build

Just do `make build`

## Install

Same here, just `make install`

## Usage

okiz \<action\> \[package/s\]

## DESCRIPTION

Okiz is a package manager that is quite small.
It will be a part of my upcoming project (hopefully).

If you are a beginner:
DON'T USE THIS AND UNINSTALL IT!
THIS PACKAGE MANAGER CAN DAMAGE YOR FILES IF USED INCORRECTLY!

Example:

	`okiz install package.tar.zst

	okiz remove package`
